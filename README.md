# NAILL TETRUS

Браузерный тетрис, в котором **имена живут внутри блоков**: каждая клетка падающей фигуры подписана случайным именем из твоего списка и светится его цветом.

## Как запустить

Просто открой `index.html` двойным кликом — игра работает без сборки, без сервера и без интернета.

Если хочется через локальный сервер:

```powershell
# из папки naill-tetrus
powershell -NoProfile -Command "$l=New-Object Net.HttpListener;$l.Prefixes.Add('http://localhost:8123/');$l.Start();while($l.IsListening){$c=$l.GetContext();$p=Join-Path $PWD ($c.Request.Url.LocalPath.TrimStart('/') -replace '^$','index.html');$b=[IO.File]::ReadAllBytes($p);$c.Response.OutputStream.Write($b,0,$b.Length);$c.Response.Close()}"
```

и открой <http://localhost:8123/>.

## Интерфейс

Игра занимает весь экран, поле — по центру и на всю высоту окна:

- **слева** — счёт, уровень, линии и рекорд;
- **справа** — «Пауза», «Меню» и кнопка **⛶** (развернуть на весь экран);
- **Меню** — выдвижная панель, где живут имена, следующая фигура, рекорды и подсказки. Открытие меню автоматически ставит игру на паузу.
- На телефоне поле сверху, статистика над ним, кнопки управления — под полем; меню выезжает снизу.

## Управление

| Действие | ПК | Телефон |
|---|---|---|
| Влево / вправо | `←` `→` или `A` `D` | кнопки ◀ ▶ или свайп |
| Поворот | `↑` `X` (по часовой), `Z` (против) | кнопка ⟳ или тап по полю |
| Ускорить | `↓` или `S` | кнопка ▼ |
| Сбросить | `Space` | кнопка «⤓ Сброс» или свайп вниз |
| Пауза | `P` / `Esc` | кнопка «Пауза» |
| Меню имён | кнопка «Меню» / `Esc` | кнопка «Меню» |
| На весь экран | кнопка ⛶ | кнопка ⛶ |

`Esc` сначала закрывает меню, и только потом снимает паузу. Меню также закрывается кликом по затемнённому фону.

## Возможности

- классический тетрис: 7 фигур, 7-bag, wall kicks, ghost-фигура, lock delay;
- меню имён: добавление, редактирование (✎), удаление (✕), очистка списка;
- сколько угодно имён, каждому — свой неоновый цвет;
- имена распределяются по клеткам случайно и остаются внутри клеток при повороте, текст всегда вписан в клетку целиком;
- счёт, уровни (каждые 10 линий), ускорение падения, таблица рекордов (топ-5);
- список имён и рекорды сохраняются в `localStorage` после перезагрузки страницы;
- игра на весь экран: поле занимает всю высоту окна, панели спрятаны в меню;
- адаптивная вёрстка: телефон, планшет, компьютер. На низком ландшафтном экране кнопки скрываются — играешь свайпами.

## Файлы

- `index.html` — разметка;
- `style.css` — неоновый дизайн и адаптив;
- `game.js` — вся логика: поле, фигуры, ввод, сохранения.
